# Lucerpy

Site institucional da Lucerpy — agência digital de UX/UI, desenvolvimento web e automações. Construído com Next.js (App Router) e Tailwind CSS, com deploy contínuo no Netlify.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) para ver o site.

## Stack

- [Next.js](https://nextjs.org) (App Router, Turbopack)
- [Tailwind CSS](https://tailwindcss.com)
- [Three.js](https://threejs.org) (esfera de partículas da home)
- Posts do blog em Markdown (`_posts/`)

## Deploy

O deploy é automático via Netlify a cada push na branch `main`.
